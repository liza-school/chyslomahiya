# Числомагія, 6 клас — індекс курсу

Учениця: Ліза. Мета: підготовка до вступу у фізико-математичний ліцей.
Назва курсу — «Числомагія»: у Гоґвортсі це справжній предмет (Arithmancy), улюблений урок Герміони.
Ритм: **одне заняття на тиждень**. Валерій дає матеріал заняття (скріни, фото, тема),
далі з нього робиться яскрава інтерактивна сторінка курсу.

Правила, за якими робиться кожне заняття: **[COURSE.md](COURSE.md)**.
Курс відкривається подвійним кліком по `course/index.html` — ні сервера, ні інтернету, ні збірки.

**Онлайн:** https://liza-school.github.io/chyslomahiya/ — те саме з телефона, нічого не качаючи.
Репозиторій: `liza-school/chyslomahiya`. Дошка всіх предметів: [Курси Лізи](https://github.com/orgs/liza-school/projects/1).

## Наступна дія

Чекаємо матеріал заняття 2. Далі — `lesson2/`, новий `l02.js` за правилами з COURSE.md.

## Як додається нове заняття

1. Матеріал лягає в `lessonN/` (скріни, фото, PDF — що є).
2. Пишеться `course/js/lessons/lNN.js` за [COURSE.md](COURSE.md).
3. Підключається в `course/index.html`, дописується в `LESSONS` у `tools/check.js`
   і в `tools/coverage.json`.
4. `cd course && node tools/check.js` — має бути «Усе гаразд».
5. Дописується рядок у таблицю вище.
